# Rust adapter documentation review

- Reviewed all nine adapters registered by the sibling Rust desktop project: Ave, AdultEmpire, AVFantasy, Carib, CaribPr, Heyzo, 1pondo, ThirdWorldMedia, and Tokyo-Hot.
- Documented their input rules, endpoints, search behavior, language support, selectors, field mappings, tests, and known implementation gaps in the knowledge base.
- Added a clear distinction between Rust reference adapters and adapters actually registered by the Android application.
- Recorded that 1pondo is a metadata-mapping stub, ThirdWorldMedia is unimplemented, CaribPr is Japanese-only, and AVFantasy has a Japanese-category mapping caveat.
- Updated the knowledge indexes and converted the Android project-status README to English while adding the adapter reference matrix.
