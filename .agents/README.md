# Agent workspace

Thư mục này chỉ dành cho tài nguyên vận hành agent, không lưu tài liệu dự án hoặc tri thức crawl.

| Thư mục | Mục đích |
|---------|----------|
| `memory/` | Ghi nhớ cục bộ theo quy ước của agent |
| `policy/` | Quy tắc bổ sung của repository |
| `prompts/` | Prompt tái sử dụng |
| `skills/` | Skill cục bộ |
| `templates/` | Mẫu dùng bởi agent |

Tài liệu dự án nằm trong [`.docs/`](../.docs/); wiki kỹ thuật nằm trong [`.knowledge/`](../.knowledge/).
